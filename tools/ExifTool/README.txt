ExifTool package for 64-bit Windows
___________________________________

This bundled ExifTool package is based on the 64-bit Windows distribution.
It includes ExifTool by Phil Harvey, Strawberry Perl, and a launcher by
Oliver Betz.

The command-line executable was renamed to "exiftool.exe" for non-interactive
use. Its runtime files are in the "exiftool_files" directory.

See "exiftool_files\readme_windows.txt" and the included license files for
third-party notices and terms. The corresponding ExifTool source archive is
available in "..\Image-ExifTool-13.59.tar.gz".
